## What you get

<CardGrid>
  <Card title="Fresh and source-traceable" icon="approve-check">
    Every value is fetched from the source and stamped with when it was retrieved. Any cache
    fallback is flagged, never silent, and the data is checked nightly against the official
    sources. See [Data freshness and provenance](/user-guide/data-freshness-and-provenance/).
  </Card>
  <Card title="Three sources, one shape" icon="puzzle">
    ABS, RBA and APRA data all come back as `metadata · series · observations`, with explicit
    series descriptors and server-version provenance.
  </Card>
  <Card title="Ask in plain language" icon="comment-alt">
    Curated concepts such as CPI, GDP growth, unemployment, the cash rate, yields, credit and APRA
    ratios, plus source-native tools for exact ABS keys, RBA tables and APRA publications.
  </Card>
  <Card title="Charts in Claude" icon="analytics">
    In clients that support MCP Apps, such as Claude, results appear as an
    [interactive chart](/user-guide/inline-charts/). Every other client gets the same JSON.
  </Card>
</CardGrid>

It is built for analysts, economists, and MCP clients, not as a general economic chatbot.
Read-only MCP resources and prompt templates cover common economist workflows.

## Current status

Version `1.21.3` is the current release line. The server remains intentionally selective: it covers
the main analyst workflows, supports stdio plus hosted Streamable HTTP, and does not aim to mirror
every ABS, RBA, or APRA release.

## Quick install

```bash
uvx ausecon-mcp-server
```

The server speaks MCP over standard input/output and is normally launched by your MCP client.
